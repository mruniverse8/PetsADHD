*petsadhd.txt*  Pixel companions and an arcade for Neovim

PetsADHD                                                  *PetsADHD* *petsadhd*

SETUP                                                       *petsadhd-setup*
    require("petsadhd").setup({})

    LazyVim: install with main = "petsadhd", lazy = false, and
    dependencies = { "folke/snacks.nvim" }. See README.md for the full spec.

COMMANDS                                                 *petsadhd-commands*
    :PetsADHD       Game and pet chooser.
    :PetTerminal    Open/resume a small bottom terminal (Node.js 18+ needed).
                    Alias: :PetsADHDTerminal. Optional mode argument:
                    pets, tetris, duel, invaders, menu.
    :PetTerminalClose  Save the terminal session and stop its process.
    :Pet67          Enable readable pixel 67.
    :PetTRex        Select the dinosaur.
    :PetDog         Select the dog.
    :PetDuck        Select the duck.
    :PetOn          Enable the habitat.
    :PetOff         Disable the habitat.
    :PetToggle      Toggle the habitat.
    :PetSmall       Small pet.
    :PetBig         Large pet.
    :PetWeather     auto, sun, or rain.
    :Tetris         Astra Tetris (aliases :AstraGame, :PetGame).
    :SpaceInvaders  Resizable ASCII Space Invaders.
    :TetrisDuel     Shared-keyboard competitive Tetris (alias :Tetris2P).

CONTROLS                                                 *petsadhd-controls*
    <leader>uP opens/minimizes/resumes the bottom pixel terminal. The existing
    sidebar remains available through :PetToggle.

BOTTOM TERMINAL                                          *petsadhd-terminal*
    Four terminal rows, with a collapsed right menu. Fine 1x pixels, detailed
    sunset, clouds, mountains, water and occasional space
    events. Pets keep animating while editing; games pause off-focus.
    n: next pet (Rex, dog, cow, duck, 67). s: four-row small layout, fine pixels.
    S: original five-row artwork. Both retain the same palette and sharp pixels.
    a: breathe fire. e: summon a black hole, supernova, comet, aurora or Saturn.
    1-4: pets/Tetris/duel/Invaders. Games expand the pane; pets shrink it again.
    m: hide and preserve. Tab: expand/collapse right menu. ?: help. M: music.
    q: discard the current game and return to the menu.
    CTRL-\ CTRL-N: Neovim normal mode, then use normal window navigation.
    Closing the split preserves the session. Reopen with :PetTerminal.
    Sessions are saved per working directory in stdpath("state")/petsadhd,
    including boards, pet selection, pixel size and animation position.
    Requires Node.js 18+, Unicode block characters and truecolor; no npm
    dependencies or browser. Existing Lua games work without Node.js.

THEMES                                                     *petsadhd-themes*
    Plugin surfaces use the current Normal background/foreground. Text, game
    colors and sidebar weather adjust for contrast on light and dark themes.
    :colorscheme refreshes open and minimized terminal sessions without
    restarting their process or modifying other buffers' ANSI palettes.
    Transparent themes use an opaque light/dark fallback. Terminal sunset
    scenery and sprite artwork preserve their original colors and details.
    VS Code follows the active light/dark or high contrast theme kind.

LUA FLOATING GAMES
    Tetris: h/l or arrows move, j soft drops, k/x rotates, z rotates back,
    Space hard drops. Invaders: h/l or arrows move, a fires, M toggles music.
    All games: m minimizes, M toggles music, p pauses, r restarts, q/Escape
    quits. Run the same command after minimizing to resume the saved game.
    Tetris: +/= speeds up, - slows down (1x-8x).
    Two players: P1 a/d/s/w move/drop/rotate, g reverse rotate, f hard drop.
    P2 arrows move/drop/rotate, / reverse rotate, Enter hard drop.
    Clearing 2/3/4 lines sends 1/2/4 garbage rows. First top-out loses.

OPTIONS                                                   *petsadhd-options*
    keymaps = false     Disable leader shortcuts uP, uA, uI.
    snacks = false      Disable automatic Snacks explorer integration.
    pets = {}           enabled, kind, size, weather, state_file.
    music = false       Start muted (M can enable music).
    tetris = {}         speed: initial speed multiplier, 1-8.
    terminal = {}       height (4), game_height (18), pixel_size (1), pet,
                        node (executable path), state_file (optional override).
    music = {}          enabled, url, volume (0-100), extractor, player.

    Game-buffer controls always remain available. Pets use saved preferences
    unless corresponding setup options are supplied. Music needs ffplay,
    yt-dlp and a supported JS runtime; the code installs nothing automatically.
